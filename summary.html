الفصل ٣: التدريب وإعداداته

Training & Hyperparameters

دورة التدريب Training Loop

📷 بيانات Input → 🤔 توقع Prediction → 📊 خطأ Loss → 🔧 تعديل Backprop → 🔄 تكرار

الإعدادات الأساسية Key Hyperparameters

دورات Epochs

عدد المرات التي يرى فيها النموذج كل البيانات. القيم الشائعة: 50-300

حجم الدفعة Batch Size

كم عينة يراها قبل التعديل. المثالي: 16-64

معدل التعلم Learning Rate

حجم خطوة التعديل. أهم إعداد! الشائع: 0.001 - 0.01

التعلم بالنقل Transfer Learning

✅ نموذج مُدرَّب مسبقاً ← نعيد تدريبه على بياناتنا

✅ يحتاج آلاف الصور فقط بدلاً من الملايين

✅ دقائق بدلاً من أيام

✅ يعمل على GPU مجاني Google Colab

مثال: طبيب عام يريد التخصص في طب العيون — لا يدرس من الصفر، فقط يتخصص!

الفصل ٤: التقييم والمقاييس

Evaluation & Metrics

الدقة Precision

من كل ما قاله "إيجابي" ← كم فعلاً إيجابي؟

TP ÷ (TP + FP)

الاستدعاء Recall

من كل الحالات الإيجابية الحقيقية ← كم اكتشفها؟

TP ÷ (TP + FN)

متوسط الدقة mAP

يجمع Precision + Recall لجميع الفئات. كلما ارتفع = أفضل

mAP@50 — الأكثر استخداماً

الخسائر الأربعة TP, TN, FP, FN

TP ✅

قال إيجابي ← وإيجابي فعلاً

TN ✅

قال سلبي ← وسلبي فعلاً

FP ❌

قال إيجابي ← لكنه سلبي (إنذار كاذب)

FN ❌

قال سلبي ← لكنه إيجابي (تفويت)

دالة الخسارة Loss

Training Loss ← يجب أن ينزل ↓ مع كل Epoch

Validation Loss ← إذا بدأ بالارتفاع ↑ = Overfitting!

أفضل نموذج = أقل Validation Loss

الفصل ٥: المشاكل الشائعة

Common Data Problems

المشكلة السبب الحل
Overfitting
الإفراط في التعلم		 يحفظ بدل ما يفهم Augmentation, Early Stopping, Dropout
Underfitting
قصور التعلم		 لم يتعلم كفاية Epochs أكثر, نموذج أكبر, تعديل LR
Imbalance
عدم توازن البيانات		 فئة مسيطرة على الباقي Oversampling, Class Weights, SMOTE
Bias
التحيز		 بيانات غير ممثلة للواقع تنويع البيانات, مراجعة التوصيف
Data Leakage
تسريب البيانات		 معلومات من الاختبار تتسرب للتدريب القسمة قبل المعالجة, لا تكرار المصادر
Noisy Labels
تسميات خاطئة		 توصيف غير دقيق مراجعة التوصيف يدوياً
